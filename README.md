# Buffet & Eventos – Portfólio  Site profissional para divulgação de serviços de buffet e eventos.
Tecnologias:
Next.js, React, CSS.
Deploy:
GitHub Pages / Vercel  ## Como usar  1. Clone o repositório 2. `npm install` 3. `npm run dev` 4. Acesse http://localhost:3000  ## Personalização  Edite os componentes em `/components` para alterar textos, preços e imagens.
